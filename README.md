# RandoMario

[![Python version](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/downloads/)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## 概要

RandoMario は、OpenAI Gym のスーパーマリオブラザーズ環境 (`gym-super-mario-bros`) を使用して、マリオを自動でプレイさせるプロジェクトです。
**バンディット学習**を実装した統計的AIエージェントが、各位置での最適な行動を学習し、効率的にステージクリアを目指します。

現在のバージョンでは、UCB1 + ε-greedy アルゴリズムによる行動選択最適化、指数減衰による非定常環境適応、Top-K多様性リプレイシステム、永続化ストレージによるセッション間学習継続など、高度な学習機能を搭載しています。
Pygame を利用して、実際のゲーム画面と、どのコントローラーボタンが押されているかを示す UI をリアルタイムで表示し、学習過程を視覚的に確認できます。

## 特徴

- **バンディット学習AIエージェント**: UCB1 + ε-greedy アルゴリズムで各位置での最適行動を統計的に学習
- **ステージ特化戦略**: 4-4, 6-2, 7-4など難ステージ用の専用行動パターン
- **適応的探索システム**: X座標ベースのリプレイ早期切り上げで多様な行動を促進  
- **自動停滞脱出**: 進捗停滞を検出して自動的に攻撃的行動に切り替え
- **学習パラメータ調整**: コマンドライン引数で学習挙動を細かく設定可能
- **永続化学習**: JSON形式でステージ別統計を保存し、セッション間で学習が継続
- **Top-K多様性リプレイ**: 複数の成功パターンを保持し、多様性を考慮した再現学習
- **指数減衰統計**: 環境変化に適応し、局所最適からの脱出を促進
- **リアルタイム UI 表示**: Pygame を使用し、ゲーム画面と押下されているファミコンコントローラーのボタンを同時に表示
- **明確な入力表示**: どのアクションが選択され、コントローラーのどのボタンに対応するかが視覚的にわかる
- **簡単な操作**: プレイ中にエピソードのリセットやプログラムの終了がキーボードから行える

## 必要システム構成

- Python 3.8 以上
- OS: Windows, macOS, Linux (一般的なデスクトップ環境)

## セットアップとインストール

1.  **リポジトリをクローン (またはファイルをダウンロード):**
    Git を使用している場合は、リポジトリをクローンします。

    ```bash
    git clone https://github.com/robustonian/randomario.git
    cd randomario
    ```

    Git を使用しない場合は、プロジェクトのファイルをダウンロードし、任意のディレクトリに展開してください。

2.  **仮想環境の作成および依存関係のインストール**
    プロジェクトのルートディレクトリで、以下のコマンドを実行して仮想環境を作成し、有効化します。

    ```bash
    uv sync
    ```

    これにより、`pyproject.toml` に記載された必要なライブラリがインストールされます。

## 実行方法

### 基本実行

```bash
# デフォルト設定（1-1ステージ）
uv run main.py

# 特定ステージを指定
uv run main.py --stage 4-4
uv run main.py -s 7-4
```

### 学習パラメータ調整

```bash
# 細かい学習（局所最適重視）
uv run main.py --stage 7-4 --x-bin-size 10 --death-penalty 40

# 高多様性探索
uv run main.py --stage 4-4 --replay-backoff 160 --epsilon 0.15

# 積極的停滞検出  
uv run main.py --stage 1-1 --stall-time 1.5 --ucb-c 1.8

# 元のランダム挙動（学習機能無効）
uv run main.py --stage 1-1 --random

# 全パラメータ表示
uv run main.py --help
```

実行すると Pygame ウィンドウが開き、バンディット学習エージェントがスーパーマリオブラザーズを自動プレイし、学習過程と対応するコントローラーの UI が表示されます。

### 学習パラメータ

| パラメータ | 範囲 | デフォルト | 効果 |
|-----------|------|------------|------|
| `--random` | - | false | **元のランダム挙動**（全学習機能無効化） |
| `--x-bin-size` | 10-40 | 20 | 小さいほど局所最適、大きいほど汎化 |
| `--replay-backoff` | 80-160 | 120 | 大きいほど早期探索、多様性向上 |
| `--stall-time` | 1.5-3.0 | 2.0 | 停滞検出の感度 |
| `--death-penalty` | 20-40 | 20 | 死亡学習ペナルティ（ステージ難度で調整）|
| `--epsilon` | 0.05-0.20 | 0.10 | ランダム探索率 |
| `--ucb-c` | 0.8-2.0 | 1.2 | UCB探索強度 |

**注意**: `--random`オプション使用時は、他のすべての学習パラメータが無効化され、バンディット学習実装前の元の完全ランダム選択に戻ります。

## 操作方法

プログラム実行中に以下のキー操作が可能です。

- **`R` キー**: 現在プレイ中のエピソードを中断し、ステージをリセットして新しいエピソードを開始します。
- **`ESC` キー**: プログラムを終了します。

## 依存関係

このプロジェクトの主要な依存ライブラリは以下の通りです (`pyproject.toml` に定義されています):

- `gym-super-mario-bros>=7.4.0`: スーパーマリオブラザーズの Gym 環境
- `pygame>=2.6.1`: ゲーム画面および UI 表示、リアルタイム学習可視化
- `numpy`: バンディット学習の統計計算とUCBアルゴリズム実装
- `matplotlib>=3.7.5`: 将来的なデータ可視化・学習曲線表示用
- `opencv-python>=4.11.0.86`: 将来的な画像認識ベースのエージェント開発用

これらのライブラリが依存する他のパッケージも一緒にインストールされます。詳細な依存関係ツリーと固定バージョンは `uv.lock` ファイル (uv を使用している場合) に記録されています。

## 技術的詳細

### バンディット学習システム

- **UCB1 + ε-greedy**: 探索と活用のバランスを最適化
- **X座標ビン分け**: 位置特化の学習統計を蓄積
- **報酬設計**: X進捗 + 死亡ペナルティによる学習促進
- **適応的リプレイ**: 成功パターンの早期切り上げで多様性確保

### AI学習機能

- **統計的行動選択**: 各位置での行動成功率を蓄積・活用
- **停滞自動検出**: 進捗停滞時の攻撃的行動への自動切り替え  
- **ステージ特化戦略**: 難易度に応じた専用行動パターン
- **パラメータ最適化**: コマンドライン調整による実験的チューニング

### 高度学習機能（v2改良版）

- **指数減衰システム**: 過去の統計に減衰係数（0.99）を適用し、環境変化への適応力を向上
- **拡張報酬システム**: 
  - 時間ペナルティ（-0.01/決定）で高速進行を促進
  - バックトラックペナルティ（-2.0）で後戻りを抑制
  - 停滞ペナルティ（-1.0）で滞留状態からの脱出を促進
- **永続化ストレージ**: JSON形式でステージ別学習統計を自動保存・読み込み（セッション間継続学習）
- **Top-K多様性リプレイ**: 
  - 最大5個の成功シーケンスを保持
  - 編集距離による多様性評価で類似パターンを回避
  - ε（20%）確率でランダム選択による探索多様化
  - リプレイ開始位置の±20pxランダム化

### 今後の拡張予定

- **コンテキスト付きバンディット**: LinUCB/Thompson Samplingによる状態特徴量を活用した学習
- **階層的オプション学習**: マクロアクション（可変時間長行動）による上位概念の獲得
- **画像認識連携**: `opencv-python`を活用したゲーム状況認識
- **強化学習統合**: DQNなど深層学習との組み合わせ
- **学習可視化**: `matplotlib`による学習進捗とパフォーマンス表示
